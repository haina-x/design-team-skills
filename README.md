# Design Team Skills

[English](README.md) | [简体中文](README.zh-CN.md)

This repository contains Codex skills for design teams. Currently, `design-uat` is the only installable skill; the `skill-placeholder-*` directories are not skills.

## Install `design-uat` with Codex

In Codex, ask the AI to install the skill from its GitHub folder. Copy this request:

```text
Use $skill-installer to install the Codex skill from this GitHub folder:
https://github.com/haina-x/design-team-skills/tree/main/design-uat
```

After Codex confirms installation, the skill will be available from your next turn. Invoke it with `$design-uat`.

For instructions on preparing a review, deciding on findings, handing work to developers, and retesting, see the [Design UAT guide](design-uat/README.md).
